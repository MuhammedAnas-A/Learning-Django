# Learning Django

My first Django project: a To Do app where you can add, edit, and delete tasks.

Built step by step as a beginner, using:

- **Python** and **Django** for the backend
- **HTML** and **Tailwind CSS** for the pages and styling
- **JavaScript** for small interactions in the browser

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/learning-django.git
   cd learning-django
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Mac / Linux
   source venv/bin/activate
   ```
3. Install Django and run the server:
   ```bash
   pip install django
   python manage.py runserver
   ```
4. Open `http://127.0.0.1:8000/` in your browser.
